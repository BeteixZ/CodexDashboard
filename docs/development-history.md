# 项目发展概述

本页记录公开版本的主要演变，不含个人运行环境、私有测试日志或任务记录。

## 桌面任务监控

项目起步于 Windows 上的 Codex 任务监控：读取本机及配置过的远程记录，提供任务列表、详情、状态筛选和最近回复。后续加入桌面 HUD、托盘视图、状态变化提醒，以及带访问密钥的只读网页监控。

## 独立助手

助手最初与监控端共处一个应用，随后拆分为独立 Windows 程序。两者分别保存配置和数据，各自管理采集与生命周期；本机配对协议只交换中立的健康和能力状态。

助手逐步接入微信、ChatGPT 账户授权、长期记忆、历史查询、提醒与订阅、文件处理以及有条件的任务控制。持久化链路记录输入、授权、操作和发送结果，区分已受理、完成和结果未知；重启不自动重发不确定操作。

## 恢复与验证

开发过程中增加了独立数据目录、备份完整性检查、历史归档、操作对账和暂停恢复副本审阅。基础创建、接续及同一任务跨重启恢复已有实际验证；正式旧版交接、恢复启用和兼容回滚仍待完成。

## 首次公开预发行

v0.1.0 提供 Dashboard 与助手两个 Windows x64 自包含安装包，随包携带运行环境。公开发行使用新的独立数据位置，不自动迁移旧版。安装程序尚未数字签名，没有自动更新。

后续用户可见变更记录在 [CHANGELOG](../CHANGELOG.md)，当前功能边界记录在 [已知限制](known-limitations.md)。
