# 开始使用

本指南适用于 v0.1.0 Windows x64 预发行安装包。两个产品可以单独使用。

## 下载安装

1. 在本仓库 [Releases](https://github.com/BeteixZ/CodexDashboard/releases) 选择对应版本，下载 `CodexDashboard-0.1.0-win-x64-Setup.exe` 或 `CodexAssistant-0.1.0-win-x64-Setup.exe`。
2. 如需校验下载，使用发布页的 SHA-256 清单。示例：

   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath '.\下载的安装程序.exe'
   ```

3. 双击安装程序，选择安装位置并完成安装。当前版本尚未数字签名，Windows 可能显示未知发布者。
4. 从开始菜单启动对应软件。安装包已经包含 .NET 运行环境和本机采集所需的 Python。

新安装使用独立数据目录，不自动导入旧版设置、凭据和微信绑定。保留原有数据；旧版迁移另见 [已知限制](known-limitations.md)。

## 配置 Dashboard

1. 打开设置，核对本机 Codex 数据目录及刷新间隔。
2. 按需配置已有的 SSH 主机。远端需要 Python 3、可读取的 Codex 记录及正常的 SSH 登录。
3. 保存设置，等待采集完成，在任务列表筛选主机、项目或状态。
4. 点击任务查看进展与最近回复；使用托盘菜单恢复主窗口、调整 HUD 或完全退出。

关闭主窗口会隐藏到托盘。提醒可在设置中单独开启；首次采集和连接恢复不会把所有历史完成任务重新通知一次。

新安装的 Dashboard 网页监控默认仅供本机访问。需要局域网 / VPN 访问时，在设置中主动开启局域网选项，并使用软件给出的链接。带访问密钥的链接仅应提供给受信任的人；在可信局域网或 VPN 使用。

## 配置助手

1. 打开 **微信与数据源…**，先核对本机数据源和助手实际保存位置。
2. 在微信连接页面扫码并按手机提示完成绑定。同一绑定只运行一个接收者。
3. 如需模型问答，打开 **模型与记忆…**，通过 **Continue with ChatGPT** 完成账户授权，按需开启问答和任务上下文。模型调用使用所选账户的额度。
4. 在微信发送“帮助”或“状态”；需要确定任务时发送“任务列表”，按回复选择，再查询“当前任务”。

可先尝试以下操作：

| 消息 | 用途 |
| --- | --- |
| `状态` | 查询当前采集状态。 |
| `任务列表` | 查看并选择目标任务。 |
| `报告` | 查询当前目标的公开最终回复。 |
| `记住：以后回答先说结论` | 保存明确的长期偏好。 |
| `查看记忆` | 查询长期记忆。 |
| `十分钟后提醒我检查结果` | 登记一次性提醒。 |
| `待发送文件` | 查看已在电脑端准备的文件。 |
| `发送文件 1` | 发送最近文件列表中的指定项。 |

问答、任务控制、附件和图片需要相应选项或能力已经开启。任务控制不会仅因存在监控记录就自动启用。遇到不明确的目标，按回复选择任务后再操作。

## 了解结果与退出

助手的 **工作与记录…** 可以查看提醒、依赖工作、操作、消息发送和对话记录。“接口已受理”只说明服务接受了请求；“结果未知”需要先核对原记录，不应靠重复发送验证。

提醒需要助手保持运行。隐藏窗口仍会后台工作；需要完全停止时，使用对应产品托盘菜单的退出入口。

## 升级与反馈

目前没有自动更新。升级前退出对应产品，再运行新版本安装程序；卸载保留独立数据。不要直接用旧程序读取新格式数据，也不要用旧备份覆盖最新状态。

遇到问题时，先查看运行诊断，记录软件版本、重现步骤及界面提示。公开反馈前删除个人路径、任务内容和访问密钥。完整限制见 [已知限制](known-limitations.md)，贡献和报告方式见 [参与开发](../CONTRIBUTING.md)。
