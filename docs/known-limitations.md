# 已知限制与验收范围

适用于 v0.1.0 预发行版。这里区分已经具备的基础能力、仍需实际验证的场景和明确未提供的功能。安装成功或测试通过不等于全部用户流程已经稳定。

## 已有基础验证

- Dashboard 和助手分别构建、运行及退出；隔离环境已验证一方退出后另一方继续运行。
- 助手基础创建、续跑、重启后读旧报告、恢复同一任务后续跑及读取新报告，已有实际手机验证。
- 自然语言记忆的保存、跨重开修改及删除，已有实际模型和持久化验证。
- 任务依赖在前置完成后只派发一次，在前置被中断后不派发，已有专用真实后端验证。
- TXT 接收、读取和回传，已有手机确认。

上述结论只覆盖对应场景，不外推到所有设备、账户、任务或故障条件。

## 尚未完成的产品闭环

| 范围 | 当前状态 |
| --- | --- |
| 旧版正式迁移 | 有迁移检查和数据保留内核，尚未完成旧接收者停机、防止重新写入、自启动处理及正式交接入口。新安装不自动迁移。 |
| 正式恢复与回滚 | 有备份、完整性检查及暂停恢复副本审阅；尚无完整的恢复服务启用流程。产生新消息或外部操作后，不能直接覆盖旧备份回退。 |

## 已实现、仍需进一步验收

| 范围 | 剩余场景 |
| --- | --- |
| 手机控制与对话 | 多任务指代、连续输入与改口、生成中停止、长报告、多消息引用、归档后恢复和异常断线。 |
| 桌面与远程控制 | 审批往返、助手与桌面同时操作、原桌面任务接续失败恢复、真实 SSH/socket 的权限和连接边界。 |
| 依赖工作 | 前置失败/取消、派发边界重启及真实并发。命令退出码为零不代表成果或全部测试正确。 |
| 记忆 | 更多项目范围、历史检索、称呼和人格一致性，以及完整手机体验。 |
| 提醒与订阅 | 长时间窗口、网络抖动、无变化静默、失败通知次数、恢复补报和手机实际收信。 |
| 媒体 | 非 TXT 格式和文件大小边界、图片手机展示、多轮指代和截图关联。 |
| 安装及稳定性 | 更广的正常桌面安装/升级/卸载、长期运行、休眠唤醒、跨账户拒绝和真实大规模采集性能。 |

## 明确的功能边界

- 当前仅提供 Windows x64；macOS 适配未完成。
- 安装程序尚未数字签名，没有自动更新。
- 提醒在助手运行时检查；退出软件或关机期间不运行。
- 语音仅使用微信附带转写，没有独立音频识别或语音回复。
- PDF 仅提取文字层，无 OCR；表格、多栏和公式的读取顺序可能不完整。
- 共享已有远程任务的审批回复不开放，需到原 Codex 处理。自建任务控制仍按后端及验收配置开放。
- 接口受理、任务派发、任务完成、成果验证和手机显示分别核对。未知结果不会自动重发。
- 删除记忆会阻止后续复用相关内容，不会删除原始对话、已发送消息或用户独立保存的备份。
- 自包含安装包只包含本机应用的运行环境。远程 SSH、远端 Python、Codex 环境和外部服务账户仍需自行配置。
