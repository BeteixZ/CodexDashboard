# 安装器简体中文翻译

来源：https://github.com/kira-96/Inno-Setup-Chinese-Simplified-Translation
固定修订：1ff90acc4ed4aee82b1cda43253243deee3daed4
ChineseSimplified.isl 原样保留，支持 Inno Setup 6.5.0+。MIT 许可见 LICENSE.txt；安装产物同时包含许可副本。构建直接使用本地文件，无需联网取最新翻译。

安装器提供简体中文和英文，由 Inno Setup 根据用户界面语言选择；未匹配语言时使用首项简体中文。用户也可在语言选择页切换。仅涉及安装界面，不更改助手聊天语言偏好。
